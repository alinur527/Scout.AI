# Evidence provenance

`small-player-2026-10-02.json` collects the independent-match baseline, bounded DEV experiments, frozen HOLDOUT baseline/candidate, actual auto-dispatched DEV runs and old-broadcast preservation reruns. Each entry retains its saved configuration, git/model/video/GT provenance, detection/tracking counts and CPU timing/RSS. Later runs also capture harness/processor hashes before inference. Candidate freeze: `821e4111042593ec5a311997c83850483d156631`; one holdout round, no retuning. This is greedy IoU>=.5 box agreement, not a standard MOT or global accuracy score.

`soccertrack-sources-2026-10-02.json` records exact official video/GT URLs, bounded HTTP ranges and hashes for three SoccerTrackv2 matches. The source decode caches are explicitly partial, while the120-frame MJPG windows are standalone. Videos and GT by Atom Scott, Ikuma Uchida, Kento Kuroda, Yufi Kim and Keisuke Fujii under [CC BY4.0](https://github.com/AtomScott/SoccerTrack-v2/blob/6f5c47cd3a5c38b074c44e9c98dfba48daa230d3/LICENSE-DATA); derived overlays/metrics by ScoutAI. GT is zero-based,22players/GK, no referee/ball; human box-review protocol is unspecified. New source/GT/model payload75,456,808bytes. Details and reproduction: [SMALL_PLAYER_EXPERIMENTS.md](../../docs/SMALL_PLAYER_EXPERIMENTS.md). `$REPO` paths are portable placeholders; all full local outputs remain ignored.

`football-2026-10-02.json` contains numeric summaries of executed local runs, not video/model assets. Original baseline: `e65bbfd`; independent visual labels frozen before football inference in `d035a83`. Baseline and production after metrics, five controlled input/tracker configurations, timestamps, frame counts, CPU duration/RSS, model/video hashes, ground-truth scopes and coordinate comparisons are separate.

Publisher GT source: UVY by Elton Alencar and Rosiane de Freitas, [Zenodo](https://zenodo.org/records/21303900), [CC BY4.0](https://creativecommons.org/licenses/by/4.0/). Ground-truth counts/identity comparisons were derived by ScoutAI; annotations were originally YOLO-World assisted with manual CVAT correction. Our independent50-frame single-player ROI labels are agent visual estimates awaiting expert review. No original video/large GT files are committed.

Detailed formulas, source frames, reproduction and limits: [FOOTBALL_VALIDATION.md](../../docs/FOOTBALL_VALIDATION.md). Full local outputs remain ignored in `test-artifacts/football/`. Processing timings are device-specific; experiment timing caveats are documented. No physical accuracy, global football accuracy, standard MOT score or CUDA validation is implied.
