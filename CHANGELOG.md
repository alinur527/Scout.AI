# Changelog

## v1.0.0 — Portfolio release candidate (2026-10-03)

Publication is held for [source-rights confirmation](docs/PROVENANCE.md#publication-status). This entry records the prepared candidate, not an assertion that a tag or public release exists.

- Private-by-default new and existing player profiles; explicit scout publication and revocation enforced on list/search/detail/report/export.
- Persistent paginated analysis history, clear DEMO/REAL onboarding and authenticated synthetic sample flow without seeded users.
- Protected JSON export, null-preserving physical metrics and print-friendly reports retaining mode/limitations.
- Alembic fresh/legacy SQLite migrations, serialized startup migration, conservative schema adoption and isolated backup/restore validation.
- Managed Windows setup/start/stop/doctor, preserved configuration/data, process identity checks and partial-start rollback.
- Docker Compose DEMO with built Nginx frontend, API, one worker, loopback port and persistent volume; CI browser coverage.
- Safe worker cleanup on locked files and sanitized user-facing failures.
- Separate E2E evidence directories, responsive/print screenshots, source/dependency notices, operations guide and bilingual portfolio material.

Production detector models/policies, thresholds, BoT-SORT, calibration vetoes and trajectory safety rules are unchanged. No new training, dataset collection, public hosting or physical-accuracy claim is included.
